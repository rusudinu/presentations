# GitHub and Flutter

A 57-slide introductory talk in two parts: Git and GitHub (repositories, branches, commits, pull
requests, the workflow a team runs every day), then Flutter (what it is, widgets, a first app).
Given as a guest session; the audience is students who have not used either before.

- **Slides:** [HE GitHub and Flutter.pptx](HE%20GitHub%20and%20Flutter.pptx)
- **Demos:** [demo/](demo/) and [demo2/](demo2/), two small Flutter projects shown during the talk.
  Run either with `flutter pub get && flutter run` inside its folder.
